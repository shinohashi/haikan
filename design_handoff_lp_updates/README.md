# Handoff: 渡邉設備 LP 更新

このパッケージは、`shinohashi/haikan` リポジトリの **ランディングページに対する一連の変更** を、Claude Code 経由でリポジトリへ反映するためのものです。

## ゴール

下記 2 つの操作を `main` ブランチで行ってください。

1. リポジトリ既存ファイル `watanabe_setsubi_lp.html` を、このパッケージに同梱されている同名ファイルで **上書き** する。
2. 新規ファイル `privacy.html` を **リポジトリ直下に追加** する（同梱版をそのままコピー）。

その後 commit & push してください。

```bash
# repo クローン済みの想定
cp <この zip 展開先>/watanabe_setsubi_lp.html ./watanabe_setsubi_lp.html
cp <この zip 展開先>/privacy.html             ./privacy.html

git add watanabe_setsubi_lp.html privacy.html
git commit -m "LP: 会社情報の仮値反映、ヒーロー本文改善、プライバシーポリシー追加"
git push origin main
```

## 受け取り側でやらないでほしいこと

- LP のヘッダーのモノグラムタイルを「復活」させない（社長レビューで撤去確定）
- `info@watanabe-setsubi.co.jp` を別ドメインに変えない（仮ドメインのまま社長確認待ち）
- 会社概要の `XX` / `◯◯` を勝手に埋めない（社長から確定値が来るまで placeholder のまま）
- ヘッダーや会社概要に括られている `19XX 年` のような書式の placeholder を「西暦らしき値」に直さない（意図的に未確定と分かる表記）

## 残りの未確定項目（社長判断待ち）

リポジトリ反映後、社長から下記の確定値が来た時点で別途差分を出します。

- 創業／設立年、資本金、従業員数
- 建設業許可番号、登録給水装置工事事業者番号
- 主要取引先・お取引銀行の社名と掲載可否
- LIXIL / TOTO「正規代理店／取扱店」表記の最終判断
- 施工実績写真（発注者・元請の掲載許可確認後）
- お問い合わせフォームの送信先（Tally / Formspree などへの接続）
- プライバシーポリシー本文の法務確認 → 正式版差し替え
