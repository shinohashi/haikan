# 配管拾い出しツール（PoC）

図面を見ながら配管の長さ・構成を拾い出し、
CSVとして出力するシンプルなブラウザツールです。

## 特徴

- 図面にノード（点）を配置
- 区間（配管）を入力
- 直管・継手・バルブを自動集計
- Excel連携用CSV（歩掛連携）を出力

## 使い方

1. HTMLをブラウザで開く
2. 図面を読み込む
3. ノードを配置
4. 区間を登録
5. CSVを出力

## 想定フロー

図面 → 本ツール → CSV → Excel（歩掛）→ 見積

## 注意

- 歩掛・金額計算はExcelで行う想定です
- 本ツールは拾い出し支援に特化しています
